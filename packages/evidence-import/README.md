# Evidence import contract

The zero-dependency CT-604 reference engine imports externally anchored
Evidence Core bundles into an immutable identity ledger. It validates canonical
units, UTC chronology, exact-version references, tenant closure, idempotency,
and append-only failure records after CT-603 integrity verification.

The ledger stores identities and fingerprints, not raw customer content. It is
an interoperability reference, not a hosted database, identity provider,
authorization service, measurement verifier, or certification authority.

See the [English guide](../../docs/evidence/import-and-idempotency-v1.md) or the
[Chinese guide](../../docs/evidence/import-and-idempotency-v1.zh-CN.md).
