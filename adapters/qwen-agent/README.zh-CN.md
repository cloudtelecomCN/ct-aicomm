# Qwen-Agent 适配状态

[English](README.md)

状态：**暂缓；目前不发布稳定生命周期适配器。**

Qwen-Agent 支持 MCP 和工具调用，但目前核对的公开资料尚不能确认存在稳定、通用的工具调用前后事件合同，能同时提供调用身份、耗时、结果/错误、传输元数据和来源信息。不应把对 Agent 内部方法的 Monkey Patch 宣称为受支持集成。等 Qwen-Agent 发布或明确版本化钩子/导出合同后再评估；在此之前，只有部署方自己的封装能无猜测地采集全部字段时，才可自行桥接。

这并非声称 Qwen-Agent 完全没有日志或追踪能力，而是 CT-AIComm 尚未核实到足以支持可复用证据适配器的稳定来源合同。
