# OTel GenAI + MCP 桥接

[English](README.md)

本映射器接收 OpenTelemetry OTLP Span 封装。MCP 元数据和载荷指纹必须通过 `index.mjs` 中定义的 `ct_aicomm.*` 桥接属性显式提供；本项目不宣称这些属性属于稳定的上游语义约定。字段要求请参见[共享证据合同](../agent-call-evidence/README.zh-CN.md)。

## 兼容边界

- 支持已结束、状态明确为成功或失败的工具调用 Span；状态未设置时拒绝转换。
- 必须提供工具名称、MCP 版本、传输方式和调用参数；成功调用还必须提供响应。
- 调用参数和响应只在内存中计算 SHA-256，不进入输出证据。
- 如果采集管道出于隐私考虑不导出载荷，则需要上游提供可验证且语义明确的请求/响应指纹字段；不能哈希整条 Span 冒充载荷指纹。
- OTel 身份属性只能映射为“声明”身份；适配器不验证凭证、主体或权限。

因此，它是需要显式埋点/桥接属性的转换器，不是安装后即可兼容任意 OTel GenAI 数据的通用 Collector 插件。
