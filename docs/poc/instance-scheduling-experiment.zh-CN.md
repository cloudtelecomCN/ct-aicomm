# 仅实例调度实验

CT-523 测量 Connector 与 Orchestrator 选择推理实例的独立作用。该实验组固定网络路径，禁止 Agent 重定向或网络策略变更。

`buildInstanceSchedulingPlan` 将同一版本化 Prompt 集分层到冻结的重复轮次与并发级别。每个有界请求窗口执行前，`runInstanceSchedulingPlan` 为所有已发现实例采集新鲜的 vLLM 负载与健康证据，复用现有候选模型和确定性“仅实例”评分，并保存完整决策解释。该策略只给队列证据与健康状态赋权；固定的网络、地域和成本控制项保留在证据中，但不能影响选择。窗口内的本地容量预留可避免并发请求同时涌向一个实例。每条样本绑定所选实例、决策回执、实验计划和 CT-521 环境指纹。

指标缺失、陈旧、降级或不存在合格候选时，执行立即停止并保持现有路径。只有与已批准 CT-522 基线完成配对分析，报告效应量、置信区间、成功率和尾延迟后，才可以形成优化结论。

首个双 A10 实测运行已发布与校验和绑定的[公开回执](../../evidence/poc/ct-523-a10-instance-scheduling-20261021.json)。仅在该冻结 POC 环境内，P50、P95、P99 和成功率声明门禁通过；回执同时公开实测效应、置信区间和明确限制，原始样本与逐请求决策仍保存在受限位置。
