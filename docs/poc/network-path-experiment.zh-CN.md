# 仅网络路径实验

CT-524 将 eBPF 数据面收益与实例调度收益严格分离。客户端入口、模型制品、Prompt 计划、生成参数、重复次数、并发分层和推理实例全部保持不变。基线组通过声明的对照路径访问该实例；实验组使用隔离 cgroup 的 `connect4` 重定向，把相同逻辑目标切换到私有 VPC 路径。

`buildNetworkPathPlan` 会拒绝相同路径、缺失的固定实例标识、合成环境和无效策略版本。`runNetworkPathPlan` 保留失败样本，并把每条样本绑定到候选路径与已应用版本。内核程序/对象哈希、映射快照、挂载证据、隧道证据和原始样本只保存在受限存储；公开仓库最多发布仅含校验和的回执。

只有分层比较同时报告效果量、置信区间、尾延迟和成功率后，才允许形成性能结论；结论仅适用于冻结的 POC 拓扑，不代表普遍生产性能。

首轮 NVIDIA A10 实测完成了 200 条对照请求和 200 条 eBPF 路径请求，成功率均为 100%。在逻辑入口没有监听器时，内核重定向仍被独立证明可执行。由于 P50、P95 的置信区间跨过 0，[公开回执](../../evidence/poc/ct-524-a10-network-path-20261021.json)仅确认真实路径执行成功，并明确不宣称 TTFT 获得改善。
