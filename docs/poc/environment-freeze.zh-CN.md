# POC 环境冻结

CT-521 要求在基线采集开始前冻结所有可能影响 TTFT 对照结果的变量。以 [`environment-freeze-v1.schema.json`](../../specs/poc/environment-freeze-v1.schema.json) 作为交换契约，并用 `freezeEnvironment` 校验完整清单、生成稳定指纹。

首个双节点 NVIDIA A10 实测环境已发布仅含校验和的[环境回执](../../evidence/poc/ct-521-a10-dual-node-20261021.json)。回执不公开主机标识、地址、凭据、受限拓扑或性能结果，仅用于把后续证据绑定到受限存储中的已批准清单。

公开示例仅为合成数据。真实 POC 必须用现场采集证据替换所有值，将完整清单与运行证据包共同保存；合作方地址、主机名、凭证和受限拓扑不得提交到本公开仓库。可公开哈希，而不公开受限原始材料。

只有模型版本与制品、加速卡、内核/驱动/运行时/vLLM、基线和候选路径、Prompt 数据集、负载、执行制品、实验窗口和具名审批全部锁定后，冻结才成立。校验器拒绝 `latest`、`unknown`、`TBD` 和待审批状态。

审批后任一字段变化都会生成新指纹，因此必须建立新的实验组。环境指纹不同的基线与实验样本不得合并统计。
