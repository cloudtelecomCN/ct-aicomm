# 联合优化实验

CT-525 将 CT-523 的实测实例决策与 CT-524 的版本化 eBPF 路径执行组合起来。每个受控请求窗口开始前，执行器采集最新的 vLLM 负载/健康和实测网络证据，应用确定性的 TTFT 联合评分，再通过被选候选实例对应的逻辑 cgroup 路径发送请求。每条样本都记录所选实例、路径标识、决策解释和已应用策略版本。

当实测证据过期或不完整、没有合格候选，或任一候选缺少版本化逻辑路径时，执行器保持静态并停止执行。原始拓扑、映射值、网络探测和请求记录继续保存在受限存储。公开结果必须将联合组与冻结基线比较，并分别报告相对于仅实例组和仅网络组的交互效应。

首轮 NVIDIA A10 实测完成 200 次决策和请求，成功率 100%，两候选实例的选择次数为 101/99。相对 400 样本冻结基线的分层 bootstrap 支持本 POC 中 P50、P95、P99 TTFT 均下降。[公开回执](../../evidence/poc/ct-525-a10-joint-optimization-20261021.json)把结论严格限定于冻结环境；由于各实验的对照路径并不完全相同，跨实验交互项明确标为探索性。
