# 基线采集门禁

CT-522 使用 `buildBaselinePlan` 和 `runBaselinePlan` 采集“保持现有路径不变”的基线。计划必须绑定 CT-521 生成且来源为 `measured` 的环境清单；公开的合成冻结示例无法通过此门禁。

首个双节点 NVIDIA A10 基线已完成每节点 200 条实测请求且无失败样本。仅含校验和的[公开回执](../../evidence/poc/ct-522-a10-dual-node-baseline-20261021.json)把两组受限原始批次绑定到已批准的 CT-521 环境；它只证明基线采集完整，不构成优化效果声明。

批次保留每一次尝试及全部失败样本，并把所有样本绑定到同一个环境指纹和确定性的计划哈希。达到样本数只表示采集结构完整，不代表性能已经改善；四个实验组齐备后才能进行统计比较。

默认方法要求每组至少 200 个真实请求和三轮重复。生产采集应加载版本化 Prompt 数据集，通过 `VLLM_API_KEY` 注入凭证，并先将结果 JSON 与原始样本保存到受限 POC 证据位置，对外只发布经批准的材料和校验和。
