# CT-Advisor 多目标分析 v1

CT-664 将通过 CT-663 Data Gate 的候选项转化为可复算的决策支持。它比较成本、预估性能、网络、交付、合规、证据可信度和风险，并保证四种情景使用同一份冻结候选数据。

## 计算顺序

1. 验证 CT-663 结果的摘要，并要求 `analysis_allowed=true`。
2. 只接收 Data Gate 标记为 `eligible` 的候选观测值。
3. 校验规范单位、数值范围、时间、引用和来源摘要。
4. 缺失指标始终保留为 `unknown`，引擎不做补值。
5. 对完整候选执行方向一致的 min-max 标准化。
6. 在情景评分前计算 Pareto 前沿。
7. 在同一输入上执行成本优先、性能优先、均衡和合规优先四种冻结情景。
8. 对每个指标权重分别上下扰动 1,000 个基点，并输出推荐稳定性范围。

## 推荐语义

均衡情景提供主要的只读推荐。每个情景都保留排名、逐指标贡献、备选项、排除原因、未知项和敏感性结果。最高分相同时明确输出并列，不会用候选 ID 暗中决定推荐对象。

结果只是决策支持，不是人工决策，也不授权采购、部署、调度、切流或回滚。它不声称全局最优、认证、保证节省或真实实测性能。

## 公开方法与样例

- `examples/advisor/multi-objective-method-v1.json` 冻结十项指标、四组情景权重和敏感性参数。
- `examples/advisor/multi-objective-fixed-input-v1.json` 将 CT-663 合成样例与带摘要的合成观测组合起来。
- `packages/advisor/multi-objective-analysis.mjs` 是确定性参考实现。
- JSON Schema 分别约束方法、组合输入和结果。

基础分析、Pareto、敏感性分析和普通推荐保持免费。后续正式收费证据包属于独立流程，不能改变这些计算结果。
