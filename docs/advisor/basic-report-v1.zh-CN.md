# CT-Advisor 基础报告 v1

CT-665 将一份通过验证的 CT-664 分析转换为可携带、免费的自助基础报告。报告保留完整分析、规范化来源观测账本、公式标识、来源指纹、限制条件和产品边界。

## 导出格式

- **JSON** 是权威结构化报告，包含完整四情景分析和分析使用的全部来源观测。
- **CSV** 是稳定的长表投影。记录类型覆盖报告身份、来源绑定、候选覆盖、归一化、Pareto 成员、情景权重和排名、指标贡献、敏感性、来源观测、限制与边界。
- **PDF** 在用户浏览器内根据已验证 JSON 本地生成。PDF 元数据写入 `CT-Advisor Basic Report <content_sha256>`，公开验证器可把它绑定回原报告；租户数据不会发送到第三方渲染服务。

## 验证

```bash
node scripts/verify-advisor-basic-report.mjs path/to/report.json path/to/report.csv path/to/report.pdf
```

JSON 摘要覆盖除摘要字段自身之外的全部报告内容；CSV 必须能够从 JSON 逐字节复算。PDF 属于展示制品：验证器检查 PDF 文件头和内嵌报告摘要标记，不宣称不同浏览器生成的像素完全一致。

## 免费产品边界

- 基础访问免费，不要求付费权益。
- 推荐为只读结果，不能产生人工决定或执行状态。
- 未知值保持未知，不进行插补。
- 估算值不会被升级为实测性能声明。
- 基础报告不是正式采购证据、正式编号报告、独立复核、认证、法律意见或容量承诺。

正式证据包合同、编号报告、人工审批记录与撤销工作流从 CT-666 及后续任务开始，本格式有意不包含这些能力。
