# 独立复核结构检查与统计复算 v1

[English](structure-and-statistical-recalculation-v1.md)

CT-618 针对一个精确的 CT-616 委托记录有限复核工作。开始前必须满足：CT-617 仅基于声明记录的门禁为可继续状态；存在一条绑定指定复核负责人的有效限时分享；护照版本与校验和已验证交付包精确匹配；委托层级为统计复算或监督重跑。

## 结构检查清单

以下七项全部通过后，参考实现才会创建记录：

1. 交付包校验和与规范重建有效；
2. 委托精确绑定该护照和交付包；
3. CT-617 门禁基于其声明记录判定为可继续；
4. 有效分享精确指向指定复核负责人及复核机构；
5. 固定的 `ct-passport-statistics-v1` 统计配置存在；
6. 尝试、纳入、排除和失败样本的数量严格闭合；
7. 独立结果完整覆盖交付包中的全部统计项。

任何结构前置条件失败都会默认阻断，不能形成“部分通过”。检查结果由程序计算，调用方不能直接提交自选的通过值。

## 独立统计复算

`recalculateIndependentReviewStatistics()` 离线读取通过校验和验证的 `samples.csv` 与 `observations.json`，独立应用声明的 IEEE-754 舍入、nearest-rank 百分位算法、样本顺序和单位目录，输出样本数量及每个观测对应的样本复算值。

指定复核负责人提交其声明复算实现的输出。CT-618 将实现标识、版本、运行环境和精确结果集绑定到记录。实现身份仍是自行声明；SDK 不证明进程、二进制、主机或操作人真实性。

## 容差与差异登记

`exact` 委托中，任何非零差异都超出容差。`declared-thresholds` 委托要求每个交付指标恰好对应一条规则；绝对容差使用指标规范单位，相对容差使用百分比。参考值为零时，只有复算结果同样为零才能满足相对容差。

每项统计结果分为 `exact`、`within-tolerance` 或 `outside-tolerance`。每个非精确结果都会生成不可变差异条目，记录期望值、复算值、绝对与相对差异、适用规则和确定性解释。全部结果精确或处于声明容差内时，摘要为 `consistent`；否则为 `deviation`。偏差作为发现被保留，不能被静默改写成无异常记录。

## 信任边界

系统要求有效分享记录，但 CT-618 不认证具名主体，也不外部核验证据导出授权。CT-617 门禁仍仅基于声明记录，不是对复核方独立性的认证。CT-618 只执行结构检查与统计比较，不重跑工作负载，不重现历史环境，不签发意见，不改变护照状态，不裁决 SLA，不形成性能结论，也不签发认证。

仓库中的全部示例均为合成数据。`consistent` 只表示提交的复算结果在声明方法与容差下和授权样本包一致。

## 离线运行

```bash
node --test tests/review-structure-recalculation.test.mjs
node examples/review/structure-statistical-recalculation-synthetic.mjs
```
