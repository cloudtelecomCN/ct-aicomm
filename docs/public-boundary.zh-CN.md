# 产品公开与专有边界

## 公共层

公开仓库定义稳定的集成合同，包括 Schema、只读 API 描述、Connector 接口、一致性检查和合成示例。第三方可以据此完成集成，但不会获得生产实现。

## CT-AIComm Enterprise 专有层

以下内容属于商业秘密和专有组件，不从本仓库分发：

- 决策、排序、评分、优化和校准算法；
- 权重、阈值、私有规则及由基准数据形成的调优数据；
- Orchestrator 路由、审批执行、流量控制和回滚实现；
- Agent Control、eBPF、生产 Connector 和客户工具执行；
- 多租户授权、计费、部署及运维实现；
- 客户、合作方、原始 PoC、拓扑和受限证据材料。

公共合同可以描述输入与输出，但不得揭示专有决策如何计算或执行。

## 声明边界

Schema 合规不等于性能结果；合成示例不等于真实测量；建议不等于执行授权；身份声明记录不等于身份认证；合规事实记录不等于法律认证。
