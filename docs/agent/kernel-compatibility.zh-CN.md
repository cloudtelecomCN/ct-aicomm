# 内核兼容矩阵

CT-583 把兼容性视为实测证据，而不是根据版本号推断。每一行矩阵都必须记录发行版、架构、内核、cgroup 模式、BTF 与 bpffs、内核 BPF 策略接口、所需程序类型、精确的预检源码哈希，以及当前对象是否在该主机完成编译和 verifier 加载。

当前初始矩阵只有一个不同平台：Ubuntu 22.04、x86_64、Linux 5.15.0-191-generic。两台独立 A10 主机均通过安装预检，并确认支持 `cgroup_sock_addr`、`sched_cls` 和 `sock_ops`；其中一台还使用 Clang 14 从当前 selector 源码重新编译，另一台未安装 Clang，因此只记录为“能力探测通过”，不能写成“本机编译通过”。

[公开回执](../../evidence/quality/ct-583-kernel-matrix-partial-20261022.json)明确标为 `partial`。同一内核在第二台主机复现能增强可重复性证据，但不能增加第二个兼容矩阵行。只有在真正不同的目标内核上完成测试，并验证不支持的环境会被预检明确拒绝后，CT-583 才能通过。
