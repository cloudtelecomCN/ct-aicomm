# 故障注入门禁

CT-519 定义五个确定性的 fail-static 场景：Agent 断连、目标故障、策略版本冲突、指标陈旧和网络抖动。模拟报告只能证明逻辑门禁，不能作为生产性能证据。

CT-526 使用独立的[`实测契约`](../../packages/qa/measured-fault-experiment.mjs)。每个场景必须记录实测恢复时间、请求数、错误数、可复算的错误率、前后状态指纹和数据完整性结论；Agent 断连必须保持静态，目标故障和网络抖动必须确认回滚，版本冲突必须拒绝陈旧版本，陈旧指标必须淘汰候选。CT-519 的合成结果不能通过 CT-526 门禁。

首轮双节点 NVIDIA A10 实测在 50 次探针中约束住全部五类故障，数据完整性保持，最大恢复时间为 780.98 ms。[公开回执](../../evidence/poc/ct-526-a10-stability-rollback-20261021.json)披露各场景恢复时间、错误率和受限证据哈希，但不宣称已达到生产可用性 SLO。
