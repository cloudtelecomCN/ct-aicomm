# 长稳测试门禁

CT-581 明确分为三个独立阶段：短时预检用于验证负载、证据管道、资源采样和失败计数；7 天运行是首个发布门禁；30 天运行是扩展运维门禁。前一阶段通过，不能推导后一阶段已经通过。

每个阶段都必须冻结模型、软件、拓扑、Prompt、负载分层和采集代码，并保留失败与缺失尝试、服务重启计数、资源趋势、健康探测和受限原始证据校验和。无法解释的进程重启、持续资源增长、缺失观测或证据完整性失败，都会阻止通过。

首轮短时预检完成 10,240/10,240 次请求，覆盖 160 个拓扑、重复轮次与并发分层。有效请求窗口约 244 秒，外围 GPU 与进程 CPU 监控约 485 秒，两端推理服务重启数均为 0。[公开回执](../../evidence/quality/ct-581-a10-soak-preflight-20261022.json)明确标记为 `partial`，因为 7 天和 30 天阶段均未运行。
