# CT-DSL 版本与兼容性

CT-DSL 的包版本和 Schema 发布元数据遵循语义化版本。文档字段 `version: 1` 表示主线格式版本，并在整个 `1.x.x` 生命周期中保持稳定。

- 补丁版本仅澄清验证行为或文档，不改变已接受的文档集合。
- 次版本可以增加可选属性或扩大允许值范围。
- 主版本可以增加必填项、删除属性、收窄允许值，或进行其他导致旧文档不再通过的变更。

兼容性检查器会把删除属性、新增必填项、收窄枚举、修改常量或类型、禁止原先允许的未知属性，以及收窄数值范围判定为破坏性变更。CI 会使用参考验证器检查所有已提交的 v1 示例，并同时覆盖兼容与破坏性 Schema 变更。
