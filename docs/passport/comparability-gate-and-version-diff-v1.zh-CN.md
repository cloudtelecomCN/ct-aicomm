# 链路证据护照可比性门禁与版本差异 v1

[English](comparability-gate-and-version-diff-v1.md)

CT-613 为 CT-612 不可变护照版本提供确定性的离线比较门禁，分别回答三个问题：

1. 两个版本是否属于同一比较组；
2. 其规范指标行是否可以并排显示；
3. 其生命周期与测量状态是否具备进入另行声明排名策略的资格。

通过门禁只说明调用方提交记录的比较语义兼容，不代表性能结论、等价性判断、独立复核、
认证或公开排行榜授权。

## 精确同组规则

冻结规则 `ct-passport-default-comparability-v1` 要求以下内容完全一致：

- 授权范围；
- 场景方向；
- 完整工作负载身份与配置指纹；
- 完整方法模板，包括工具制品、参数、采样、排除规则、统计项和环境前提；
- 声明的数据来源；
- 观测形状，即来源、观测点、指标、聚合和规范单位。

站点和协议是明确的比较维度。比较链路或协议选择往往正是视图目的，因此二者可以变化而
版本仍属于同组；差异清单仍会以 `comparison_dimension` 显示变化，不表示二者等价。

不同方法或工作负载的版本不得进入默认并排指标视图或排名，只能留在
`difference-only` 区域并展示稳定阻断码和字段级差异。方向、数据来源、单位、指标形状或
授权范围发生变化时采用相同处理。

## 版本与字段差异

每个候选版本都包含 JSON Pointer 路径，并分为：

- `comparison_dimension`：站点和协议；
- `ranking_blocker`：必须完全一致的同组字段；
- `eligibility`：生命周期或测量状态差异；
- `metadata`：版本、有效期、身份和指纹差异。

字段值以规范 JSON 字符串表示，使另一实现可以显示或散列精确差异，而无需猜测格式。
完整比较记录不可变，并由规范 SHA-256 内容指纹保护。

## 视图与排名边界

同组版本进入 `side-by-side-unranked`；不同组版本进入 `difference-only`，不会出现在
指标行中。只有仍处于活动状态、测量有效性为 `sufficient` 且全部观测质量为 `valid` 的
版本才会标记为 `ranking_eligible`，但参考 SDK 仍固定输出
`default_ranking_applied: false`。使用方必须另行提供并披露排名目标、方向、并列规则和
发布策略。

评估器依据调用方提供的终态事件历史投影到期、替代和撤销状态。已到期或其他非活动版本
默认失去排名资格。公开包不读取权威事件流；生产调用方必须提供完整且经授权的事件历史。

## 离线示例

```bash
node examples/passport/comparability-gate-synthetic.mjs
```

示例创建一个精确同组候选、一个工作负载漂移候选和一个方法漂移候选。所有数据均为合成
数据，不访问外部网络，也不授权任何性能或认证声明。
