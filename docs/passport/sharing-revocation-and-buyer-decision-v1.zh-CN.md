# 链路证据护照分享、撤销与买方决定 v1

[English](sharing-revocation-and-buyer-decision-v1.md)

CT-615 在 CT-614 离线交付包之上增加受治理的交接记录。发布方可以把一个精确护照版本及一个精确交付包，在有限时间内绑定给一个具名接收方。接收方可以按类别请求补证，发布方或运营方可以用不可变制品引用回应，接收方随后可记录自己的接受或拒绝决定。

买方接受只是限定于该买方的商业决定，不会改变平台证据状态、独立复核状态、新鲜度、策略状态、底层护照或任何认证状态。

## 记录模型

| 记录 | 用途 | 不可变边界 |
|---|---|---|
| `passport_share_grant` | 将一个接收方绑定到精确护照和已验证交付包，直至 `expires_at` | 不含 bearer 密钥，也不证明身份或导出授权 |
| `passport_share_revocation` | 在到期前停止后续使用 | 仅追加，不修改授权记录或护照 |
| `passport_supplement_request` | 列出缺失的方法、环境、来源、排除或授权上下文 | 只含请求，不含原始证据 |
| `passport_supplement_response` | 用 `provided` 或 `unavailable` 闭合每一项请求 | 只嵌入哈希引用，不嵌入原始制品字节 |
| `passport_buyer_decision` | 为该接收方记录一次最终 `accepted` 或 `rejected` | 保存证据和分享状态快照，但不改变它们 |

每条记录都经过规范化，并由 `sha256:` 内容指纹保护。引用包含对象类型、对象 ID、语义版本、租户和精确内容指纹。未知字段、重复项、引用漂移和指纹漂移都会默认失败。

## 分享有效期

授权从创建时刻开始，且到期时刻必须晚于创建时刻。授权不能早于已验证交付包的创建时间，不能晚于护照版本有效期，也不能晚于护照授权范围的有效期。只有授权记录和精确护照版本同时有效时，访问才处于有效状态。

到期状态直接由时间推导，即使定时事件丢失也不会让访问继续开放。有效撤销从其记录时刻生效，一个分享最多接受一条仅追加撤销。到期、撤销或护照失效后创建补证请求、响应或新决定，均默认失败。

公开记录不是 bearer URL、令牌、会话、身份认证结果或授权服务。实际部署仍须单独执行接收方身份认证和交付访问控制。

## 补充证据

补证请求记录必须填写精确接收方；SDK 会验证这一绑定，但不认证调用者身份。每个请求项都有稳定 ID 和一个类别。响应必须对每项请求准确闭合一次。`provided` 项必须提供 `artifact_ref`，`unavailable` 项必须为 `null`。

制品引用只证明命名了哪一组不可变字节，并不交付这些字节，也不授权导出。任何受保护制品传输前，仍须单独执行 CT-606 导出授权及其审计台账。

同样，发布方、运营方和买方 ID 只是结构化记录字段。SDK 不认证这些主体，也不判断其是否拥有所填写的角色；实际部署必须在本包之外提供相应权威上下文。

接受决定引用的每个补证请求都必须有完整响应；拒绝决定可以把未解决缺口保留为买方理由的一部分。

## 买方决定边界

一个分享最多接受一个最终买方决定。记录包含：

- 精确买方、分享、护照和补证引用；
- 决定时刻的有效分享快照；
- 决定时刻有效且已封存的护照生命周期与状态轴；
- 决定专属理由代码及人读说明；
- 平台状态修改、继承复核、性能声明和认证均恒为 false 的边界字段。

后续分享撤销或护照到期不会抹去历史买方决定。投影视图会独立返回已记录的买方决定和当前访问/证据状态。因此，历史接受不能被解释为当前访问、当前新鲜度、策略接受、独立验证、SLA 裁决或认证。

## 离线示例

使用 Node.js 22 或更高版本运行零网络合成场景：

```bash
node examples/passport/sharing-buyer-acceptance-synthetic.mjs
```

示例创建一项含两个哈希引用响应的补证请求、一项接受后被撤销的决定，以及另一项独立拒绝决定。输出证明：历史接受仍可审计，当前访问已经关闭，而平台证据状态保持不变。

公开实现、类型与 schema 位于：

- `packages/link-evidence-passport/sharing.mjs`
- `packages/link-evidence-passport/sharing.d.ts`
- `specs/passport/passport-sharing-v1.schema.json`

仓库中的全部样例均为合成数据，不是生产实测性能、身份声明、导出授权、独立复核、SLA 裁决或认证。
