# Phase 2 扩展决策

CT-534 将**规模测试**确定为 Phase 2 的立即工程优先项，其次是真实 Kubernetes 验证。在形成一个可重复的集群交付前，多云继续后移；在网络单变量实测识别出实质性包处理瓶颈并形成有支持的效果目标前，XDP/DPDK 保持暂停。

机器可读的[决策记录](../../evidence/architecture/ct-534-phase2-expansion-decision-20261021.json)引用 CT-523 至 CT-526 和 CT-530。实例调度与联合路径在一个冻结环境中出现有边界的收益；eBPF 网络单变量实验证明了真实执行，但没有证明统计显著的 TTFT 改善。因此，下一步应先验证可迁移性与容量，而不是投入更侵入式的数据面。

该决策只授权工程规划，不构成广泛性能声明。对外把实测 POC 结果表述为“已验证”前，仍必须完成 CT-527 独立审核和 CT-528 发布。每个扩展方向都定义了进入门禁与退出证据，可在不改写既有证据的前提下重新评估优先级。
