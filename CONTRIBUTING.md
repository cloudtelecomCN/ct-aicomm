# Contributing

Contributions are limited to public schemas, documentation, connector interfaces, conformance tests, and clearly labelled synthetic examples.

Before opening a pull request:

1. confirm that the contribution contains no confidential or third-party restricted material;
2. label all example data as synthetic;
3. run `npm test` with Node.js 22 or newer;
4. do not submit decision weights, scoring logic, routing logic, execution controls, deployment configuration, credentials, customer data, or measured data without a separate written publication approval.

Maintainers may reject a contribution solely because it crosses the public product boundary.
